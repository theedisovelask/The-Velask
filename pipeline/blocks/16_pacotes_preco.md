# Bloco 16 — Pacotes e Preço

## Objetivo
Transformar a proposta em oferta vendável: três pacotes claros, com diferença real, e uma recomendação de qual oferecer a {{ cliente.nome }} dado o cenário dele.

## Tarefa
Gere os 10 itens, todos no formato `### NNN — Título`. Para preços, use referências de mercado realistas para o nicho **{{ cliente.nicho }}** no Brasil; se incerto, marque com `[SUPOSIÇÃO: ajustar conforme política Velask]`.

Para 161–163 (pacotes), use a estrutura:
```
**Promessa:** ...
**Entregas mensais:** ...
**Investimento mensal:** R$ ...
**Para quem é:** ...
```

- 161 — Pacote essencial (mínimo viável da operação Velask)
- 162 — Pacote crescimento (intermediário, com tráfego e mais conteúdo)
- 163 — Pacote gestão completa (operação 360, gestão visível, tráfego, automação)
- 164 — Escopo de cada pacote (tabela comparativa: o que tem em cada um)
- 165 — Entregas de cada pacote (consolidado mensal de cada pacote)
- 166 — Diferença entre pacotes (3 linhas explicando a "salto" entre eles)
- 167 — Preço sugerido (resumo dos três preços + lógica)
- 168 — Condições de pagamento (à vista, mensal, anual, fidelidade)
- 169 — Bônus possíveis (3-5 bônus de fechamento — pra usar como gatilho)
- 170 — Oferta recomendada para {{ cliente.nome }} (qual pacote oferecer, com argumento de venda)
