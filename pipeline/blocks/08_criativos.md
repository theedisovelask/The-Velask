# Bloco 08 — Criativos / Vídeos / DR

## Objetivo
Mostrar a máquina de criativos da Velask: volume + qualidade + variedade. Cliente precisa enxergar que vai ter material novo toda semana, não só "uns posts".

## Tarefa
Gere os 10 itens, todos no formato `### NNN — Título`. Onde pedir lista numerada, gere a quantidade exata.

- 081 — Ideias de criativos de venda (10 ideias, foco em conversão direta)
- 082 — Hooks para Reels (10 hooks de 1ª linha curtos e fortes para {{ cliente.nicho }})
- 083 — Hooks para anúncios (10 hooks de 1ª linha pensados para Meta Ads)
- 084 — Roteiros curtos (3 roteiros completos de 15-30s, formato: cena/fala/CTA)
- 085 — Roteiros UGC (3 roteiros para criador parecer cliente real)
- 086 — Roteiros de prova social (3 roteiros usando depoimento / antes-depois)
- 087 — Roteiros de bastidor (3 roteiros mostrando processo / equipe / dia a dia)
- 088 — Roteiros de oferta (3 roteiros focados em uma oferta específica de {{ cliente.nome }})
- 089 — Direção visual dos vídeos (paleta, fonte, transições, ritmo — diretrizes claras)
- 090 — Checklist de edição (passos do raw ao publicado, com pontos de qualidade)
