# Bloco 06 — Escopo de Execução

## Objetivo
Definir exatamente o que a equipe Velask vai fazer se {{ cliente.nome }} fechar. Esse escopo é usado internamente e também aparece na proposta.

## Tarefa
Gere os 10 itens, todos no formato `### NNN — Título`.

Para as fases 01–07, use:
```
**Duração estimada:** ...
**Responsável principal:** ...
**Entregas:** ...
**Marco de conclusão:** ...
```

- 061 — Fase 01: organização inicial (setup do projeto, acessos, alinhamento)
- 062 — Fase 02: estruturação digital (bio, destaques, link, identidade)
- 063 — Fase 03: conteúdo (calendário, posts, Reels recorrentes)
- 064 — Fase 04: criativos (vídeos de venda, anúncios, UGC)
- 065 — Fase 05: funil (oferta, copy, landing, WhatsApp)
- 066 — Fase 06: tráfego (campanha, criativos, otimização)
- 067 — Fase 07: acompanhamento (rotina, relatório, otimização contínua)
- 068 — Lista de entregáveis (consolidação geral, agrupada por fase)
- 069 — Lista do que o cliente precisa enviar (acessos, materiais, decisões — checklist)
- 070 — Checklist de início do projeto (passo a passo do dia 1 ao dia 14)
