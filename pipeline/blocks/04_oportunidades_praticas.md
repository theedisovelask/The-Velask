# Bloco 04 — Oportunidades Práticas

## Objetivo
Transformar o diagnóstico (Bloco 03), as brechas do mercado (Bloco 02) e o mapa do nicho (Bloco 01) em oportunidades que viram receita para {{ cliente.nome }}.

## Tarefa
Para cada oportunidade abaixo, use a estrutura:

```
**O que é:** ...
**Por que importa para {{ cliente.nome }}:** ...
**Impacto esperado (3 meses):** ...
**Entrega Velask:** ...
```

Gere os 10 itens, todos no formato `### NNN — Título`.

- 041 — Oportunidade de melhorar bio
- 042 — Oportunidade de melhorar link da bio
- 043 — Oportunidade de criar Trello/gestão visível
- 044 — Oportunidade de criar calendário de conteúdo
- 045 — Oportunidade de criar Reels (volume e padrão)
- 046 — Oportunidade de criar criativos de venda
- 047 — Oportunidade de criar landing page
- 048 — Oportunidade de organizar WhatsApp
- 049 — Oportunidade de tráfego pago
- 050 — Oportunidade de automação com IA
