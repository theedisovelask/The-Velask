# Bloco 11 — WhatsApp / Direct / Atendimento

## Objetivo
Mostrar que a Velask não só posta — organiza o caminho da venda até o caixa. Cada mensagem aqui é texto pronto pra colar como resposta rápida.

## Tarefa
Gere os 10 itens, todos no formato `### NNN — Título`. Mensagens devem soar humanas, não robotizadas, e refletir o tom de {{ cliente.nome }}.

- 111 — Mensagem automática (primeira mensagem quando o lead chega — pronta)
- 112 — Resposta para orçamento (texto pronto, com qualificação leve)
- 113 — Resposta para preço (texto pronto, ancorando valor antes de soltar número)
- 114 — Resposta para dúvida (template flexível para dúvidas comuns)
- 115 — Resposta para objeção (3 objeções comuns no nicho + resposta pronta)
- 116 — Follow-up 24h (texto pronto pra reabrir conversa)
- 117 — Follow-up 72h (texto pronto, tom diferente do 24h)
- 118 — Mensagem de fechamento (texto pronto pra empurrar a venda)
- 119 — Etiquetas do WhatsApp (lista de 6-10 etiquetas para organizar funil)
- 120 — Fluxo de atendimento (passo a passo desde o primeiro contato até pós-venda)
